# Registre « à vérifier »

Détails techniques (Event ID, formats de sortie, libellés, chemins…) reconstitués de mémoire d'expert et **non confirmés par une capture**. Un faux détail réaliste étant pire qu'un détail absent, chaque entrée est à confronter à une machine réelle ou à une capture avant diffusion.

- **aduc-gui** — Utilisateurs et ordinateurs Active Directory : arborescence (Builtin, Computers, Domain Controllers, ForeignSecurityPrincipals, Managed Service Accounts, Users), colonnes Nom/Type/Description, onglets Général/Compte/Membre de, grille des horaires d’accès, boîtes « Réinitialiser le mot de passe » et « Sélectionner des utilisateurs… » reconstitués de mémoire (version française).
- **aduc-gui-limits** — ADUC : seuls les onglets Général, Compte et Membre de d’un utilisateur, Général et Membres d’un groupe sont simulés (adresse, profil, téléphones, organisation, appel entrant, etc. absents) ; les horaires d’accès sont exprimés en UTC ; la suppression d’une unité d’organisation est refusée comme pour un objet protégé.
- **aduc-msg** — ADUC : textes des messages (compte désactivé/activé, confirmation de suppression, mot de passe réinitialisé, échec de complexité, accès refusé, objet protégé contre la suppression) reconstitués ; à vérifier par capture.
- **apt-format** — Messages d’apt (tailles, numéros de version, lignes Get:/Fetched) : approximation ; seuls les échecs réseau suivent des libellés connus.
- **bash-errors** — Messages d’erreur coreutils / bash en anglais (« No such file or directory », « Permission denied », « command not found »…) : formes courantes de Debian 13, reprises de mémoire.
- **bash-script-errors** — Messages de bash pour un script erroné (« script: line N: unexpected EOF while looking for matching `"' », « syntax error: unexpected end of file », « DEST: command not found ») : formes reconnues de bash 5.2, numéros de ligne rapportés à confirmer par essai sur une vraie Debian 13.
- **boot-emergency** — You are in emergency mode. After logging in, type "journalctl -xb" to view system logs, "systemctl reboot" to reboot, or "exit" to continue bootup.
- **browser-gui** — Navigateur : pages d’erreur (« Impossible d’accéder à ce site », ERR_NAME_NOT_RESOLVED, ERR_CONNECTION_TIMED_OUT, ERR_CONNECTION_REFUSED, ERR_ADDRESS_UNREACHABLE), page « Votre connexion n’est pas privée » (NET::ERR_CERT_*), pages d’erreur IIS et libellés reconstitués de mémoire, sans reprendre le logo ni la police d’un éditeur ; à vérifier par capture.
- **browser-gui-proxy** — Navigateur, erreurs liées au proxy : ERR_PROXY_CONNECTION_FAILED, ERR_TUNNEL_CONNECTION_FAILED (titre « Désolé, impossible d’accéder à cette page », cité par la fiche de TP) et ERR_SSL_PROTOCOL_ERROR (titre « La connexion de ce site n’est pas sécurisée », cité par la fiche de TP) ; les textes d’explication sont reconstitués.
- **certlm-gui** — Certificats (ordinateur local) : magasins Personnel et Autorités de certification racines de confiance, colonnes et assistant « Inscription de certificats » (renouvellement avec la même clé auprès de CA-FormaTech) simplifiés et reconstitués de mémoire.
- **compmgmt-ui** — Gestion de l’ordinateur : arborescence (Outils système, Dossiers partagés, Utilisateurs et groupes locaux, Services et applications) et partages par défaut (C$ « Partage par défaut », ADMIN$ « Administration à distance », IPC$ « IPC distant ») — libellés à vérifier par capture. Planificateur de tâches, Gestion des disques, Gestionnaire de périphériques et Performances non simulés.
- **cron-insecure** — Message de cron pour un fichier de /etc/cron.d modifiable par le groupe ou les autres : « INSECURE MODE (group/other writable) » — libellé à vérifier sur Debian 13.
- **cron-nomta** — Ligne syslog de cron quand la tâche produit une sortie et qu’aucun MTA n’est installé : « (CRON) info (No MTA installed, discarding output) » — à vérifier sur Debian 13.
- **cron-shell-err** — Messages d’erreur du shell lancé par cron (dash : « /bin/sh: 1: <cmd>: Permission denied » / « not found ») — à vérifier sur Debian 13.
- **curl-win-errors** — Messages d’erreur de curl.exe sous Windows (schannel) : formulation exacte non vérifiée pour les erreurs de certificat.
