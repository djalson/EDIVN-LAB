# Liens de révision : compétences → site de cours

> Généré par `node tests/gen-docs.js` depuis `src/content/28-course-links.js`. Ne pas éditer à la main.

Quand un ticket n’est **pas validé** (note < 75 / 100, abandon ou temps écoulé), le débrief propose « À réviser avant de repasser ce ticket » : des liens vers les cours, procédures et TP du site de formation **https://tssr.miyukini.com** (site d’un camarade de formation), choisis d’après les compétences de la panne.

## Règles

- **Hôte fixe** et chemins écrits dans la table : aucune URL n’est fournie par un scénario, un fichier importé ou le joueur.
- Liens en `target="_blank" rel="noopener noreferrer"` ; connexion internet nécessaire (le jeu lui-même reste hors ligne, la CSP du jeu n’est pas modifiée : ce sont de simples liens).
- Au plus 8 liens par ticket ; les compétences techniques passent avant `diag` / `diag-gpo` (méthode), qui ne servent que de repli.
- Les 50 compétences de la fiche ont au moins un lien (testé : `tests/course-links.js`).

## Vérification et limites

- Chaque chemin a été ouvert sur le site avec le navigateur intégré pendant la rédaction (octobre 2026), **titre de page contrôlé** : le site est rendu côté client et un chemin inconnu répond quand même HTTP 200 avec un titre générique, donc le code HTTP seul ne prouve rien. Le contrôle en ligne n’est pas rejouable depuis la batterie de tests (réseau du poste de dev restreint).
- Si le site renomme ou supprime une page, seul le lien concerné casse : mettre à jour la table `src/content/28-course-links.js` puis relancer `node tests/gen-docs.js`.
- **Aucun cours nginx** sur le site : la compétence `nginx` renvoie vers les virtualhosts Apache (le plus proche) et le libellé le dit.
- Le site couvre aussi des sujets **hors fiche de compétences** (OSPF, HSRP, OPNsense…) : ils ne sont jamais proposés ici, pour ne pas élargir le périmètre du jeu. Deux pages OPNsense (`/opnsense-nat`, `/opnsense-segmentation`) servent d’illustration au NAT / à la segmentation faute de page pfSense dédiée : à confirmer.
